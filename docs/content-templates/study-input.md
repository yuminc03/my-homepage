# 스터디 재료 양식
스터디 글을 부탁할 때 채워서 주는 양식입니다. [study.md](study.md)가 **사이트에 올라가는 글의 틀**이라면, 이 문서는 **그 글을 쓰기 위해 넘겨주는 재료의 틀**입니다.

맨 뒤의 빈 양식을 복사해 채워서 주시면 됩니다. **다 채우지 않아도 됩니다** — 4(정리)는 비워 두시면 제가 초안을 써서 보여 드립니다.

세미나와 달리 스터디는 **필기와 코드가 곧 재료**입니다. 다듬지 않은 메모 그대로 주셔도 됩니다.

## 1. 글 정보 (필수)

| 항목 | 설명 | 예 |
|---|---|---|
| 제목 | 무엇을 정리한 글인지 | `Swift Concurrency에서 actor 격리 이해하기` |
| 카테고리 | **딱 하나만.** 목록 위 필터 칩이 됩니다 | `Swift`, `SwiftUI`, `iOS`, `아키텍처` |
| 날짜 | 공부한 날 또는 쓴 날 | `2026-09-25` |
| 왜 공부했나 | 도입 문단이 됩니다. 어떤 문제를 만나서 찾아보게 됐는지 두세 줄 | 마이그레이션 중에 `@MainActor`가 왜 필요한지 몰라서 |

> **카테고리는 가나다 순으로 칩이 만들어지고, 두 개 이상일 때만 칩이 보입니다.** 이전 글과 같은 이름을 쓰면 한 칩으로 묶이니, 새로 만들기 전에 기존 글의 카테고리를 확인하는 편이 좋습니다.

## 2. 내용 (필수)
**필기 그대로 주셔도 됩니다.** 반말·오타·순서 뒤섞임 모두 괜찮습니다. 제가 문장으로 다듬고 소제목으로 묶습니다.

| 항목 | 설명 |
|---|---|
| 본문 | 무엇을 알게 됐는지. 소제목을 나눠 주셔도 되고, 죽 이어 쓰셔도 됩니다 |
| 코드 | 있으면 꼭 주세요. **파일 이름을 함께** 주시면 코드 블록에 머리줄이 붙습니다(`Lesson.swift` 같은 식) |
| 참고한 글·문서 | 주소만 주시면 **북마크 카드**(제목·설명·썸네일)로 들어갑니다. 여러 개도 됩니다 |
| **공개하면 안 되는 것** | 회사 코드·사내 규칙·계약 관련 내용 등. **적어 주시면 글에서 뺍니다** |

> 마지막 칸을 꼭 봐 주세요. 업무 중에 배운 것은 회사 코드가 섞이기 쉽습니다. 알려 주시면 개념만 남기고 예시 코드를 새로 짜서 씁니다.

## 3. 막혔던 것 (있으면 — **글에서 제일 값어치 있는 부분입니다**)
결론만 정리한 글은 검색하면 나옵니다. **틀렸다가 고친 기록**은 본인만 쓸 수 있습니다.

| 항목 | 설명 |
|---|---|
| 처음에 어떻게 생각했나 | 잘못 알고 있던 것 |
| 어디서 막혔나 | 에러 메시지·이상하게 동작한 것 |
| 어떻게 알아냈나 | 무엇을 찾아보고 무엇을 바꿔 봤는지 |
| 결국 무엇이었나 | 원인과 고친 방법 |

## 4. 정리 (선택 — 비워도 됩니다)
비어 있으면 2·3의 내용으로 제가 초안을 써서 보여 드립니다. 읽어 보시고 고치면 됩니다.

| 항목 | 설명 |
|---|---|
| 목록 카드에 보일 두 줄 | 나중에 다시 찾을 때 보이는 문장 |
| 한 줄로 줄이면 | 이 글의 핵심 |
| 더 알아보고 싶은 것 | 있으면 |

## 5. 사진·그림 — **없어도 됩니다 (있으면 1~2장)**
스터디 글은 대부분 **글과 코드만으로 충분합니다.** 아래 둘 중 하나일 때만 넣습니다.

| 넣는 경우 | 예 |
|---|---|
| 글로 설명하기 어려운 구조 | 손으로 그린 다이어그램, 메모리·흐름도 |
| 결과를 보여 줘야 할 때 | 실행 화면, 디버거·Instruments 화면 |

- **코드로 보여 줄 수 있으면 코드로 씁니다** — 코드 블록이 줄 번호·복사 버튼까지 붙어 더 쓸모 있습니다
- 화면을 찍으실 때는 **필요한 부분만 잘라서** 주세요. 전체 화면은 글에서 작아져 안 읽힙니다
- **제3자의 이름·사내 정보·토큰이 찍힌 것**은 주셔도 됩니다. 그 부분만 잘라내고 씁니다

## 참고: 자동으로 되는 것
채우지 않으셔도 되는 것들입니다.

- **읽는 시간** — 글자 수로 계산합니다
- **목차** — `##` 소제목으로 자동 생성(모바일은 접힘 상자, 데스크톱은 오른쪽 레일)
- **코드 블록** — 줄 번호·복사 버튼·구문 강조
- **검색** — 제목·요약·카테고리·본문 전체가 색인에 들어갑니다
