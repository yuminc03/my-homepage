# 세미나 재료 양식
세미나 기록을 부탁할 때 채워서 주는 양식입니다. [seminar/index.mdx](seminar/index.mdx)가 **사이트에 올라가는 글의 틀**이라면, 이 문서는 **그 글을 쓰기 위해 넘겨주는 재료의 틀**입니다.

맨 뒤의 빈 양식을 복사해 채워서 주시면 됩니다. **다 채우지 않아도 됩니다** — 모르거나 없는 칸은 비워 두세요. 비어 있으면 그 항목을 글에 넣지 않고, **4(소감)만은 예외로 제가 초안을 써서 보여 드립니다.**

Notion에 이미 적어 두셨다면 [6번](#6-notion에-적어-두셨다면)만 보셔도 됩니다.

## 1. 행사 (필수)

| 항목 | 설명 | 예 |
|---|---|---|
| 정식 이름 | 행사 포스터·티켓에 적힌 그대로 | `10 Years of Let'Swift` |
| 날짜 | 하루짜리 기준. 이틀 이상이면 시작일과 함께 적어 주세요 | `2026-04-01` |
| 장소 | 건물 이름 + 지역. 목록 카드에 한 줄로 들어갑니다 | `Apple Korea 아셈타워, 서울 강남` |
| 주최 | 기관·커뮤니티 이름. 없으면 비워 둡니다 | `Let'Swift` |
| 공식 링크 | 홈페이지·신청 페이지 하나. 본문에 **북마크 카드**로 들어갑니다 | `https://letswift.kr/2026/` |
| 어떤 행사였나 | 왜 갔는지, 어떤 자리였는지 두세 줄 | 10주년 기념 밋업. 발표 50분 + 그룹 토론 60분, 35석 |

## 2. 세션 (세션마다 하나씩, 순서대로)
발표가 여러 개면 이 묶음을 반복해 주세요. 세션 목록은 이 내용으로 **자동으로 만들어집니다**(표지 아래 "세션 한눈에 보기", 목록 카드의 "세션 N개").

| 항목 | 설명 |
|---|---|
| 제목 | 발표 제목 그대로 |
| 발표자 | 이름 또는 닉네임 |
| 시간 | `15분`처럼. 없으면 비워 둡니다 |
| 내용 | **여기가 제일 중요합니다.** 필기한 그대로 주셔도 됩니다 — 소제목·글머리표·반말·오타 모두 괜찮습니다. 제가 문장으로 다듬습니다 |
| 특히 기억에 남은 것 | 한두 줄. 이걸 주시면 글에서 굵게 강조합니다 |
| **공개하면 안 되는 것** | 발표자의 미공개 자료·수치·사내 사례 등. **적어 주시면 글에서 뺍니다** |

> 마지막 칸을 꼭 봐 주세요. 필기에 들어 있어도 공개 자리에 올리기 애매한 내용(발표자가 따로 분석한 수치, 회사 사례 등)은 미리 알려 주시면 다른 내용으로 대체합니다.

## 3. 발표 말고 다른 순서 (있으면)
그룹 토론·네트워킹·핸즈온 등. **무엇을 했고 어떤 이야기가 오갔는지** 두세 줄이면 충분합니다. 발표가 아니라서 세션 수에는 안 들어가고, 도입이나 소감 문단에 녹입니다.

## 4. 내 소감 (선택 — 비워도 됩니다)
**이 묶음은 통째로 비워 두셔도 괜찮습니다.** 무엇이 기억에 남았는지는 2의 세션 내용에 이미 녹아 있는 경우가 많아서, 비어 있으면 그 내용을 바탕으로 제가 초안을 쓰고 보여 드립니다. 읽어 보시고 고치면 됩니다.

적어 주시면 그대로 씁니다.

| 항목 | 설명 |
|---|---|
| 목록 카드에 보일 두 줄 | 목록에서 이 행사를 고르게 만드는 문장 |
| 배운 점 | 행사 전체를 돌아보며. 내 일·내 앱과 이어지는 게 있으면 특히 좋습니다 |
| 다음에 해 보고 싶은 것 | 있으면 |
| 기억에 남은 순간 | 사람들과 나눈 이야기, 사소한 일화 등. 글 마지막을 닫는 데 씁니다 |

## 5. 사진 — **2~3장, 많아야 4장**
폴더 경로를 주시거나 그냥 올려 주세요. **고르고 자르고 크기 줄이는 것은 제가 합니다** — 후보를 넉넉히 주셔도 됩니다.

**넣는 구성**

| 자리 | 장수 | 어떤 사진이 좋은가 |
|---|---|---|
| 표지 | **1장(필수)** | 목록 카드와 공유 카드에 함께 쓰입니다. **가로로 넓게 잘려도 읽히는 것** — 행사 배너, 무대·스크린 정면, 행사장 전경 |
| 본문 | **1~2장** | ① 흐름이 보이는 것(진행 순서·타임테이블 화면) ② 분위기(행사장, 사람들 뒷모습) ③ 개인적인 것(이름표·굿즈·필기) 중에서 |
| 최대 | **4장** | 이보다 많으면 글이 사진에 밀립니다 |

**되도록 피하는 것**
- **발표 슬라이드를 찍은 사진 여러 장** — 저작권이 애매하고, 화면 속 글씨는 어차피 잘 안 읽힙니다. 슬라이드 내용은 글로 옮기는 편이 낫습니다
- 얼굴이 알아볼 수 있게 나온 사진(본인 제외)
- **제3자의 이름·연락처·QR·좌석 번호가 찍힌 것** — 주셔도 됩니다. 그 부분만 잘라내고 씁니다

**형식**: 원본 그대로 주세요(가로 사진이 좋습니다). 파일 이름은 아무래도 괜찮습니다.

## 6. Notion에 적어 두셨다면
페이지를 그대로 읽을 수 있습니다. 다만 **`app.notion.com/...` 주소는 열리지 않습니다**(로그인이 필요한 사설 페이지).

1. Notion에서 해당 페이지 → **공유 → 웹에 게시**
2. 생긴 `<워크스페이스>.notion.site/...` 주소를 주세요
3. 하위 페이지(세션별 페이지 등)도 주소를 함께 주시면 각각 읽습니다

이 방식이면 본문과 **사진까지** 모두 가져오므로, 위 1~5를 따로 안 채우셔도 됩니다. 다만 **2의 "공개하면 안 되는 것"** 은 Notion 필기만 봐서는 제가 판단할 수 없으니 꼭 알려 주세요.

즉 Notion에 적어 두셨다면 **최소한 이 정도면 됩니다.**

```markdown
- notion.site 링크(행사 + 세션별):
- 사진 폴더:
- 공개하면 안 되는 것:
- 표지로 쓰면 좋을 사진 / 빼야 할 사진:
```
