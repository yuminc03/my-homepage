모션 설계
데스크톱·모바일·태블릿 공통 모션 토큰과 인터랙션별 값입니다. 옆의 두 프로토타입(데스크톱 · 모바일)이 이 값 그대로 움직입니다. 태블릿은 모바일 값을 따릅니다.
원칙
01 빠르게 반응하고 부드럽게 멈춘다 누르는 순간 120ms 안에 반응하고, 움직임은 감속 곡선(ease-out)으로 끝을 길게 둔다. 300ms를 넘는 것은 화면 전체가 바뀌는 전환뿐이다.
02 들어올 때보다 나갈 때 빠르게 닫기는 열기의 약 60~70% 시간에 가속 곡선(ease-in). 사용자가 이미 떠나기로 한 화면을 붙잡지 않는다.
03 출발점을 보여준다 데스크톱 창은 누른 아이콘·메뉴·Dock 쪽에서 커지고, 모바일 창은 Dock이 있는 아래에서 올라온다. 상세는 오른쪽에서 들어와 뒤로 가면 오른쪽으로 나간다.
04 줄이기 설정을 존중한다 기기의 "동작 줄이기"가 켜져 있으면 이동·확대를 모두 짧은 페이드로 바꾸고, 등장 애니메이션과 반복 모션을 끈다.
곡선과 시간 토큰
감속 (기본) --ease-out: cubic-bezier(0.2, 0.8, 0.2, 1) 들어오는 모든 움직임, 호버, 누름, Dock. 기존 Dock 숨김 곡선을 기본값으로 삼았다.
가속 (나가기) --ease-in: cubic-bezier(0.4, 0, 1, 1) 닫히는 창·시트. 시작은 느리고 끝이 빨라 화면에서 빠르게 사라진다.
시트 --ease-sheet: cubic-bezier(0.32, 0.72, 0, 1) 모바일·태블릿 창 시트. 초반에 빨리 올라와 마지막 20%를 길게 감속한다.

구현 메모
CSS만으로 구현 모든 값은 CSS transition·@keyframes와 custom property 토큰으로 표현했다. 프레임워크를 정하기 전이라도 그대로 옮길 수 있고, 모션 때문에 JS 라이브러리를 더하지 않는다.
transform·opacity만 움직인다 레이아웃(width·top 등)을 바꾸지 않아 브라우저가 합성 단계에서 처리한다(리플로우 없음). 흐림(blur) 값은 애니메이션하지 않는다.
스크롤 등장 IntersectionObserver(threshold 0.15)로 한 번만 클래스를 붙인다. 스크롤 이벤트마다 계산하지 않는다.
동작 줄이기 @media (prefers-reduced-motion: reduce)에서 reduced 규칙을 적용한다. 프로토타입의 motion 칩(system / full / reduced)으로 두 모드를 비교할 수 있다.
